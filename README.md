# AUROBO

Interactive Scroll Animation Experience.

**Live Demo:** [https://aurobo.vercel.app/](https://aurobo.vercel.app/)

## Overview
This project features a high-performance, scroll-driven image sequence animation built with HTML5 Canvas, Tailwind CSS, and vanilla JavaScript. It smoothly interpolates 300 high-resolution frames as the user scrolls, seamlessly transitioning into a fully styled landing page.
